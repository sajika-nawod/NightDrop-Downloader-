# NightDrop Pro

Local media downloader UI with:
- URL preview + thumbnail
- Video quality selector
- MP4 / MP3
- Separate download/progress page
- Live percentage, speed and downloaded size

Requirements:
- Node.js 18+
- yt-dlp
- FFmpeg

Install yt-dlp:
`py -m pip install -U yt-dlp`

Install FFmpeg and add it to PATH.

Run:
`npm install`
`npm start`

Open http://localhost:3000

Use only for content you own or are authorized to download.
